# LumeMC Support Bot (@LumeMc_Bot)

Python 3.10+ / aiogram 3 / SQLite. Запуск: `pip install -r requirements.txt && python main.py`

## Настройка
1. Токен вводится на сайте хоста (переменная `BOT_TOKEN`), в коде его нет.
2. Группа (`GROUP_ID`) — супергруппа с включёнными **Темами**. Бот — админ с правом «Управление темами».
3. Для `/mpmute` и `/setadmin` по @нику человек должен хоть раз написать боту или в группу (или используй ответ на его сообщение).
4. Если нужно ограничить команды темой «Команды боту» — укажи её id в `COMMANDS_TOPIC_ID`.
5. Хранилище: `data/bot.db` (на хосте убедись, что папка сохраняется между перезапусками).

## Символы номеров
Обращение `#` · Жалоба `№` · Обжалование `%` · Заявка на модератора `!` · Заявка на медиа `$` (у каждого своя нумерация). Меняются в `config.py`.

## Команды (в группе)
- `/mpmute @ник 30m причина` (s/m/h/d/w), `/mpunmute @ник`
- `/setadmin @ник 1/2` (0 — снять). Владельцы — любой уровень, админ 2 — только уровень 1.
- Ответ игроку: в теме написать `+текст`.
- Жалобы на модератора и обжалования берут только админ 2 уровня и владельцы.
